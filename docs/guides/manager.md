# Manager guide

* **Review queue:** unplaced items and low-confidence suggestions; resolve with one click, or ignore. Unlinked tasks offer the three most likely deliverables.
* **Views:** list, board, pipeline, matrix, gantt, calendar, now - filters are chips, state lives in the URL, "Add to presentation" turns any view into a slide.
* **Plans:** a project can be planned top-down (phases -> deliverables -> milestones -> dependencies). The roadmap editor moves dates inline; **Approve plan** records a baseline; variance and slips are tracked against it. **Present this plan** builds the review deck.
* **Presentations:** start from a template (they are data - duplicate and edit them), reorder, present, export PPTX/PDF/PNG, share a link (if your admin enabled sharing). **Generate with AI** drafts a deck from a sentence; external model workflow: download the pack, paste the answer into *Import*.
* **Policies:** pick a template, set scope/candidate filter/notify/automatic action, **dry-run** (writes nothing), activate. Violations can be acknowledged, resolved or waived (a reason is mandatory); version history shows every edit and restores any.
* **Habits:** patterns over time per person with sparklines; coaching notes are manager-only. Wellbeing habits are visible only to the person and their line managers.
* **Weights, performance, digest, insights:** configure weight schemes (preview before saving), read team series, review daily logs, read project insights (generated only from facts, with a fallback when no model is available).
